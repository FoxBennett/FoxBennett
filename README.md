### How I work

- **Scope before code.** Inputs, outputs, edge cases and acceptance criteria
  confirmed in writing. If something is unclear or out of scope, you hear it
  before the work starts, not after.
- **AI-assisted, human-verified.** AI tooling speeds the work up; it never
  replaces review. Every release is checked by automated tests and by
  inspecting the actual rendered output.
- **Small, visible increments.** Work is split into steps you can see and react
  to, so correcting course stays cheap.
- **You own the result.** Source code, setup instructions and handover notes
  ship with every deliverable.
